# ophix-lang-de-docs

> Deutsches Übersetzungspaket für ophix-docs.

German translation pack for [ophix-docs](https://ophix.io).

## Install

```bash
pip install ophix-lang-de-docs
```

Then set `LANGUAGE_CODE = "de"` in your server `.env`.

## What is translated

- Admin UI strings: app label, model field labels and help text
- Documentation page: ophix-docs system guide
